# FreeConnect 0.5.0

**Обход Telegram стал заметно надёжнее, а VPN для Discord — стабильнее.**

- **Telegram** переведён на новое ядро обхода: соединение держится крепче и поднимается быстрее, настройка — по-прежнему в один клик.
- **VPN для Discord** работает стабильнее: через туннель идёт только Discord, всё остальное — напрямую.

**Установка:** скачай `FreeConnect-Setup.exe` ниже и запусти. Обновление поверх работает без удаления старой версии.
